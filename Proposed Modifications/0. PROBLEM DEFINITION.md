## New Features I want to build



I want the website to have three sections. The first section is already built which takes in RSS feeds in the form of articles and summarises them for me.



The second section should be focused around YouTube. What I wanted to do is take some of the creators that I follow on YouTube, run a daily scraper to extract the transcript that will help me analyze what their video is all about for me and then grouped by the creator. I want to be able to view what videos they released each day and get a summary of the same so that I can decide if I want to view the full video. Even if I don't want to view the full video, the summary should give me a good gist of all the details that were covered in that video. This should have all the same functionality as the RSS articles wherein I should be able to add the creators that I want to follow using the UI itself.



The third section should be focused around podcasts. The functionality should be the exact same as YouTube wherein I should be able to follow creators, extract their transcripts and get summaries so that I can make a decision on what podcast to watch and what to not.



On a side note, if I can have the functionality of OAuth so that the YouTube channels that I follow and the YouTube podcasts that I follow can be directly linked using my account so that I don't have to add them manually, that would be great.
