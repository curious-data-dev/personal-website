# YouTube UX Redesign: Digest + Vertical Channel Layout

**Date:** 2026-06-14  
**Status:** Approved for implementation  
**Branch:** `feature/youtube-intelligence`

---

## 1. Problem Statement

The current YouTube page (`/youtube`) dumps full transcripts and long-form summaries into a vertical list. With 10–20 channels each posting 2–3 videos daily, this becomes a never-ending scroll that takes hours to read — defeating the core promise of the app: *save time without losing detail*.

The RSS digest page works brilliantly because of a two-layer information rhythm: a synthesized narrative you read in 2–3 minutes, followed by compact source footnotes you can expand if curious. The YouTube page must adopt this same pattern.

---

## 2. The Two-Layer Rhythm (Same as RSS)

| Layer | What it is | Interaction | Time |
|-------|-----------|-------------|------|
| **Layer 1 — Digest Card** | A single synthesized narrative. `##` topic headings group related videos across channels. Bullet points surface key takeaways. `[[N]]` source references link to footnotes. | Read linearly | 3–4 min |
| **Layer 2 — Video Footnotes** | Collapsed `<details>` section. One line per video: `[N] Title | Channel | Duration`. Click a footnote row to expand — reveals the full LLM summary, key points, and a ▶ Watch button. | Skim 15 sec; expand 1–3 items | 1–2 min |

**Total: ~5 minutes for up to 60 videos/day.**

### 3.2 Space Allocation

| Zone | Width | Behavior |
|------|-------|----------|
| App Sidebar | 220px (52px collapsed) | Sticky, full height |
| Channel List | ~170px | Sticky, `overflow-y: auto`, scrolls independently |
| Main Content | Remaining | Digest + footnotes, scrolls normally |

### 3.3 Channel List Details

- **"All Channels"** always pinned at top, selected by default
- **Active channels** listed alphabetically below
- **Paused channels** grouped at the bottom under a subtle "Paused" divider, grayed out
- **Count badge** — e.g., `ThePrint (3)` shows 3 new videos from that channel today
- **Click a channel** → filters the digest + footnotes to only that channel's videos
- **Two-line truncation** for long channel names

### 3.4 Per-Channel View

| State | What you see |
|-------|-------------|
| **Channel posted today** | Filtered digest of that channel's videos + their footnote cards |
| **Channel hasn't posted today** | Message: *"X hasn't posted today."* Below: the channel's most recent summaries (past 7 days) in card format |

### 3.5 Video Footnote Row

**Default (collapsed):**
```
[1] (MARKET CRASH) Will upcoming Mega IPOs crash the Market?  |  Akshat Zayn  |  18 min
```

**Expanded (click to toggle):**
```
[1] (MARKET CRASH) Will upcoming Mega IPOs crash the Market?  |  Akshat Zayn  |  18 min  ▶ Watch

Akshat argues that Anthropic's IPO at a $60B valuation, combined with OpenAI and
SpaceX going public, will create a $200B+ liquidity event that siphons capital from
emerging markets. He points to FII outflows of $4B from Indian equities in Q2 as an
early warning sign...

Key points:
- Anthropic IPO expected Q4 2026 at $55–65B valuation
- Combined IPO calendar could pull $200B+ from global markets
- Indian retail investors should watch FII flow as leading indicator
- Historical parallel: 2021 IPO boom preceded 2022 correction
```

- **Expand/collapse** is toggled by clicking the row (client-side, no page reload)
- **▶ Watch** opens the YouTube video in a new tab
- **Key points** are extracted by the LLM as part of the summary prompt

## 4. States & Edge Cases

| State | Behavior |
|-------|----------|
| **No channels added** | Empty state: "You're not following any YouTube channels. [Add your first channel → /settings]" |
| **No videos today (any channel)** | Empty state: "No videos today. The daily scrape runs at 8 PM IST." |
| **Channel list exceeds viewport** | Vertical `overflow-y: auto` scrollbar within the channel column |
| **Mobile (<768px)** | Channel list collapses to horizontal scrollable pills above the digest (like Instagram story pills) |

## 5. Database Changes

| What | Why |
|------|-----|
| New table: `youtube_digests` | Stores synthesized YouTube digests. Same structure as `daily_digests`. Separate table guarantees zero risk to RSS pipeline. |
| New table: `youtube_digest_videos` | Links `youtube_digests` → `articles`. Same pattern as `digest_articles`. |

## 8. LLM Prompt

The YouTube digest uses a prompt similar to the RSS daily digest but tuned for video content. Key differences:

- Instructions to **group by topic**, identifying how different creators approach the same story
- Instructions to **surface controversy/conflict** — when two creators disagree
- Output format identical to RSS digest: `## Topic Headings`, `- Bullet takeaways`, `[[N]] source references`

Prompt lives at `Main Architechture/prompts/youtube_digest.md`.
