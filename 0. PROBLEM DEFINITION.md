# Problem Statement

I'm a fairly busy individual who wants to be updated with day to day news and events, but the problem that I face is that in today's day and age there are so many news articles that people publish which lack a lot of substance, but the content of those articles is humongous. So it becomes difficult to keep track of world events, news, what's happening. In order to solve this I want to Build a summarization service which Accumulates data from various news articles in the form of RSS or in general web scraping Which summarizes all of this information in easy to consume paragraphs on a daily basis, which enriches my understanding of the world.


# What I've built

In order to solve this problem, I have already written a Python script which accumulates data from RSS feeds, sends the information to an AI model posted on cloud. Which summarizes all of the information. And then hits the google SMTP servers to send me a daily email with. The highlights of what has happened in the day.

# The problem with what I've built

There are two major problems with what I have built. Problem number one is that for some RSS feeds which I want to follow. The scraping seems to work on my system, but when? The code runs on git actions on an Ubuntu machine. The scraping itself fails. Problem number two is even if the scraping is successful. There is a hard limit on how many on how much information can I send to the? Online AI provider because I am restricted by tokens. Problem number three is. Even if I do send. The entire article to the online AI Provider. The success of this process is dependent upon if the AI provider is running or not, or in general the uptime of the AI system. All of these things make the existing process prone to failure. In addition to This, I also want The functionality to be able to look back at historical scraped summaries. So that I can. Draw some. Temporal inference on how events have changed in the current setup. Since I get a daily mail, it is not possible to, let's say, look back 30 days and see what was. The main news summary back then.
