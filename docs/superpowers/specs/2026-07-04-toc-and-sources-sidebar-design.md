# TOC & Sources Right Sidebar — Design Spec

**Date:** 2026-07-04
**Status:** Approved

## Overview

Add a right-hand sidebar to content pages containing two sections:
1. **Table of Contents (TOC)** — exhaustive heading hierarchy extracted from digest/article text
2. **Sources** — numbered list of `[[n]](url)` citation links from the digest text

Both sections are rendered server-side from existing content — no DB changes, no regeneration needed.

## Layout

```
┌──────────┬──────────────────────┬─────────────────────┐
│  Left    │                      │  📑 On this page    │
│  Nav     │   Main Content       │  ├─ Heading 1       │
│  (240px) │   (adapts width)     │  ├─ Heading 2       │
│          │                      │  └─ ...             │
│          │                      │                     │
│          │                      │  📡 Sources         │
│          │                      │  1. Source A →      │
│          │                      │  2. Source B →      │
│          │                      │  ...                │
└──────────┴──────────────────────┴─────────────────────┘
```

- Fixed position, right edge, full viewport height
- Width: ~220px (collapsible on mobile / narrow viewports)
- Top padding to align with main content area
- Takes right-side space currently empty

## Components

### 1. TOC Section

**Data source:** Parsed from `summary_text` (or `raw_text` for article page) at render time — server-side Python extraction.

**Extraction rules:**
- `## Heading` → top-level TOC entry
- `### Subheading` → indented TOC entry
- Generate `id` attributes on corresponding `<h2>`/`<h3>` elements in the rendered content for anchor linking

**Behavior:**
- Clicking a TOC entry smoothly scrolls to the corresponding heading
- Current heading is highlighted as the user scrolls (optional, stretch goal)
- Independently scrollable if TOC exceeds available height

**Stretch:** `h4`-level headings if any appear in content (unlikely but exhaustive per spec)

### 2. Sources Section

**Data source:** Parsed from digest/article summary text at render time.

**Extraction rules:**
- Find all `[[N]](url)` patterns — these are citation links generated by the LLM summarizer
- Extract the number and URL for each
- Resolve article titles from the database when available; fall back to domain name from the URL

**Display:**
- Numbered list: `1. Article Title →` (linked to original)
- If title unavailable: `1. example.com →`
- Externally-linked (`target="_blank"`)

## Files to Change

| File | Change |
|------|--------|
| `app/web/routes.py` | Add helper functions to extract TOC headings and citation sources from markdown; pass extracted data to templates |
| `app/web/templates/base.html` | Add right sidebar HTML structure and CSS |
| `app/web/templates/index.html` | Add `id` attributes to rendered headings; adjust main content max-width |
| `app/web/templates/article.html` | Add `id` attributes to rendered headings; ensure content renders with anchor-able headings |
| `app/web/templates/youtube.html` | Same treatment for YouTube digest page |
| `app/web/static/output.css` | Add right sidebar styles (or use Tailwind utility classes inline) |

## Files NOT to Change

- Database schema — no new tables or columns
- Summarizer pipeline — no changes to how digests are generated
- Migration scripts — no migration needed
- Existing digest content — works immediately with all historical data

## Styling

- Follows existing patterns: same `Inter` font family, `text-sm`, `font-medium`
- Uses CSS custom properties (`--ink`, `--text-muted`, `--border`, `--bg`) for dark mode
- Border and spacing follow `border-gray-200 dark:border-slate-800` conventions
- Active TOC item uses `sidebar-link-active` color: blue (`#2563eb` / `#60a5fa`)

## Edge Cases

- **No headings in content:** TOC shows "No headings" placeholder or is hidden
- **No citations in content:** Sources section shows "No sources" placeholder or is hidden
- **Very long TOC or source list:** Section scrolls independently with `overflow-y: auto`
- **Mobile / narrow screens:** Right sidebar hidden below a breakpoint; TOC/sources not critical on small screens
- **YouTube content:** May not have markdown headings; TOC may be empty — section gracefully degrades
- **Collapsed left sidebar:** Right sidebar remains; main content width adjusts accordingly

## Testing

- Verify TOC renders correctly with mixed `h2`/`h3` content
- Verify source links open in new tab with correct URLs
- Verify dark mode appearance
- Verify no flicker — sidebar content present in initial HTML payload
- Verify existing digests work without regeneration
